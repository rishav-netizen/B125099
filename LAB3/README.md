## 📖 About

This folder contains my **Lab 3** solutions for the **Object-Oriented Programming Laboratory**.

The programs practise dynamic memory allocation in C++ using `new` and `delete`, including dynamically allocated values, arrays, character arrays, objects, arrays of objects, and two-dimensional matrices.

> **Institute:** International Institute of Information Technology, Bhubaneswar  
> **Department:** Computer Science and Engineering  
> **Course:** Object-Oriented Programming Laboratory  
> **Lab:** 3 – Dynamic Memory Allocation

- ✅ Dynamic character arrays and string analysis
- ✅ Classes and dynamically allocated objects
- ✅ Dynamically allocated arrays of objects
- ✅ Dynamic two-dimensional arrays
- ✅ Memory cleanup and `nullptr`
